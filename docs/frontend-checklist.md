- [x] **Отображение:** Список категорий подгружается и корректно отображается в UI.
- [x] **Поиск:** Реализована и проверена фильтрация категорий по названию.
- [x] **Создание:** Добавление новой категории через форму работает (данные сохраняются).
- [x] **Редактирование:** Изменение названия существующей категории работает.
- [x] **Удаление:** Удаление категории после подтверждения работает.

## 2. Общие сценарии
- [x] **Авторизация:** Сценарии входа и регистрации проверены (на Mock-данных).
- [x] **Задачи:** Страница задач отображает список и основные атрибуты (приоритет, дедлайн).
- [x] **Интерфейс:** Переключение тем (Светлая/Темная) работает корректно.

## 3. Замечания по результатам тестов
1. **Инфраструктура:** Наблюдаются сложности с локальной сборкой бэкенда на Windows 10/11 (конфликты библиотек шифрования с Python 3.12). Тестирование UI проведено с использованием Mock-клиента.
2. **Отказоустойчивость:** При получении от API данных в неверном формате (например, массив вместо объекта) страница может уходить в "белый экран". Рекомендуется добавить проверку типов данных и Error Boundaries.
3. **Навигация:** Замечены редкие случаи, когда при использовании навигации браузера ("Назад/Вперед") требуется ручная перезагрузка для корректного рендеринга страницы.

**Заключение:** Функционал управления категориями полностью реализован и готов к интеграции с бэкендом.
